Play Elden Ring Seamless Co-op

Use the installer to set up the mod, then join your friends with matching settings.

Get started

  1. Open PowerShell and run: 
    irm https://psykzz.github.io/eldenring-coop-installer/install.ps1 | iex
  2. Follow the prompts to choose your release and install location.
  3. Choose a co-op password and save filename. The default for both is crab.
  4. Optionally copy your base-game saves and create a desktop shortcut, then start Seamless Co-op.

To play together, everyone should use the same Seamless Co-op version and co-op password. Launch the modded game through Seamless Co-op, not the regular Elden Ring launcher.

Frequently asked questions

Can I keep my existing characters?

Yes. You can choose to copy your base-game save into a separate Seamless Co-op save. Your original save is left untouched. Each save file contains all of your character slots.

What should I use for the password and save filename?

Use the same co-op password as your friends. You can keep the default crab or choose another password and save filename during setup.

Which mod version should we choose?

Choose the same version as the other players in your group. The installer defaults to version 2.0.1 and lets you select a newer release if one is available. Check the release page if you need to compare versions.

Where can I review the installer?

You can read the PowerShell installer script before running it.

Can I create a desktop shortcut?

Yes. The installer offers to create one if a Seamless Co-op shortcut is not already on your desktop.
