Elden Ring Seamless Co-op Installer

Run this command in PowerShell to download and start the interactive installer:

irm https://psykzz.github.io/eldenring-coop-installer/install.ps1 | iex

This downloads and executes a script from this site. Review the script at install.ps1 before running it if you want to inspect what it does. It defaults to Seamless Co-op 2.0.1 and offers a left/right-arrow choice if a newer release is available. See the GitHub release page. It checks the archive against GitHub's SHA-256 metadata and asks before installing.

The installer finds your Steam game folder, backs up an existing mod installation, and keeps your current Seamless Co-op settings. The co-op password and save filename default to crab and can be changed during installation. Before launch, it can copy base-game saves to Seamless Co-op save files without changing or deleting the originals. Start modded sessions with ersc_launcher.exe, not the normal game launcher. Match the mod version and co-op password with your party.
